## 三条被推翻的结论（勿再引用）

1. **「324,000 € 加 12 把枪 = 0 漏发」** — 错。实测 24 点位 + 无跨柜 = **8 辆漏发（1,040.1 kWh）**，比 12 枪的 3 辆更差。`324,000 €` 只买到插枪位，不增加柜功率（仍 1,080 kW），单枪从 90 kW 腰斩到 45 kW。
2. **「柜扩容可以清零」** — 半错。`3×450 kW` 确能达到 0，但峰值 **1,350 kW 超出 1,200 kW 电网限值**；`3×400 kW` 刚好等于限值却仍漏发 4 辆。**在限值内任何「加硬件」方案都到不了 0。**
3. **「2,616 行 `delivered_kw > grid_limit_kw`」** — 错，应为 **2,621 行**（五种容差 0 / 1e-9 / 1e-6 / 1e-3 / 0.01 全部复现 2,621）。

**唯一在 1,200 kW 限值内能清零的路径**：现有 12 枪 + 跨柜母线互备（峰值仍 1,080 kW、0 人工挪车），而该母线不在 `chargers.csv` 物理连线中、`equipment_costs.csv` 无报价 —— 故表述为**已定位的能力边界**，不得宣称「花钱买到 0」。
