# Project Sentinel - Self-Operating Charging Network · Hackathon Command Center

> Generated at: 2026-11-05 16:28 | Track: **Kempower Challenge: The Self-Operating Charging Network** | Deadline: **Saturday 2026-11-07 12:00 EET**

## Mission
Build the smallest real system that proves the idea — demonstrable, clear narrative, strictly rules-compliant.

## Core Directives
1. **Demo First**: Every line of code serves the 2-minute live demo. "Does this make the demo better?" If no, drop it.
2. **Runtime Evidence**: "Compile pass" != "Function works". Every done claim must have a 5-second reproducible command.
3. **Timeline Gates**:
   - **Hour 4**: End-to-end pipeline walks through (hardcoded mock allowed).
   - **Hour 16**: Feature freeze. No new logic. Only bugfixes that affect the demo.
   - **Hour 20**: Demo video recorded (60-90s) & backup slides finalized.
   - **-30 min**: Final submission completed on Devpost / platform.
4. **Scope Hammering**:
   - **Vital 20%**: 1 end-to-end workflow + 1 "Aha!" moment + 2 polished demo screens.
   - **Cut 80%**: Auth, admin panel, profile settings, edge error recovery, complex user roles.
5. **Fallback Triad**:
   - Live demo failed -> Switch to 60s backup video.
   - External API down -> Switch to local pre-baked JSON mock.
   - Network down -> Switch to localhost offline fixture.
