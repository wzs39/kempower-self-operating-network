### 7-Section Devpost Copy
1. **Inspiration**: Concrete data/incident that inspired the project.
2. **What it does**: 2 sentences explaining the core value + 3 bullet points.
3. **How we built it**: Architecture diagram + breakdown (Frontend, Backend, Sponsor APIs).
4. **Challenges we ran into**: Real engineering obstacles overcome.
5. **Accomplishments that we're proud of**: Working end-to-end in <24 hours.
6. **What we learned**: Deep dive insights on the new stack/APIs.
7. **What's next**: 3 actionable roadmap items.
